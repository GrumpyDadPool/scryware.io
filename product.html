How it works

Three moving parts, one calm dashboard.

1

Deploy the reporters

Lightweight agents install on each endpoint and dial out to the hub. No inbound firewall rules, no VPN, no exposed ports on the machines you watch.

2

Watch the fleet

The hub collects health reports from every reporter. The Command Center — a browser console — shows the whole fleet's status, with role-based access and dual authentication for your team.

3

Heal in real time

Queue remediation commands from the hub and let the system correct problems as they happen. Underneath sits a stateful diagnostic agent that inspects network status, analyzes logs, executes safe scripts, and retains conversation context across turns.

What's inside

Built for the realities of running other people's infrastructure.

  • Command CenterBrowser-based fleet console: health reports, remediation queue, ops chat, and access management — from any device on your LAN.
  • Endpoint reportersLightweight agents that dial out to the hub. Designed for fleets of Windows and Linux machines.
  • Diagnostic agentA modular, stateful agent that inspects network status, analyzes logs, runs safe scripts, and remembers context across conversations.
  • Self-healingQueue remediation centrally; the system corrects problems in real time instead of paging you at 3 AM.
  • Versioned REST APIA stable API for managing the fleet programmatically — script it, integrate it, automate it.
  • Security modelDual authentication, role-based access, and cookie login. Built assuming hostile networks.
