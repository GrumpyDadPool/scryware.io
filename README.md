# scryware.io

The Scryware company website, hosted with GitHub Pages at https://scryware.io.

Static HTML and CSS. No build step. Edit and push to `main` to publish.

Pages: `index.html`, `product.html`, `apps.html`, `company.html`, `testers.html`, `focusup-research.html`, and `privacy.html`. `adhd-research.html` and the older per-app privacy URLs are redirect stubs.
