# scryware.io

The Scryware company website, hosted with GitHub Pages at https://scryware.io.

Static HTML and CSS. No build step. Edit and push to `main` to publish.

Pages: `index.html`, `product.html`, `apps.html`, `games.html`, `company.html`, `testers.html`, `focusup-research.html`, `privacy.html`, and the per-app pages `app-brain.html`, `app-cashglance.html`, `app-doomsday-tycoon.html`, `app-focusup.html`, `app-homeglance.html`, `app-legalglance.html`, `app-umbra-field.html`, and `app-wallpaper-watcher.html`. `adhd-research.html` and the older per-app privacy URLs are redirect stubs.
